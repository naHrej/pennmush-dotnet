# Archived Parity & Porting Logs

They are kept for historical reference only and are no longer maintained as live checklists. For the authoritative, codebase-verified view of implemented features, PennMUSH.NET extensions, and remaining partial command switches, see:

- **[PennMUSH 1.8 Parity and Differences](../wiki/PennMUSH-1.8-Parity-and-Differences.md)**
