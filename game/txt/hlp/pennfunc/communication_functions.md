Communication functions are side-effect functions that send a message to an object or objects.

```text
  cemit()       emit()        lemit()       message()     nsemit()
  nslemit()     nsoemit()     nspemit()     nsprompt()    nsremit()
  nszemit()     oemit()       pemit()       prompt()      remit()
```
